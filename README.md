# trailbrief-media

Public video files for Trailbrief's social posts (Instagram Reels, TikTok, YouTube Shorts). The site itself is trailbrief.app.

**Why this repo exists:** to post a video, YouTube's upload page and Buffer both need it at a public web link. Hosting videos here keeps them off the website, so posting never changes trailbrief.app or uses Netlify credits.

## Layout

```
videos/YYYY-MM/YYYY-MM-DD-short-name.mp4
```

Each file's public link:

```
https://raw.githubusercontent.com/trailbriefhq/trailbrief-media/main/videos/YYYY-MM/YYYY-MM-DD-short-name.mp4
```

## Rules

- **Public repo.** Anyone with a link can download these files. Only finished ads go here: never customer plans, intake answers, emails or anything private.
- Videos are 1080x1920 MP4 (H.264 + AAC), under 50 MB each (GitHub warns at 50 MB and refuses 100 MB).
- Keep the repo small: once a video has been posted everywhere, it can be deleted. The posts stay up on the platforms.
- Same posting rules as the playbook: show "trailbrief.app" in full, label realistic AI voices on every platform, and don't state permit dates that weren't re-checked on the official page that day.
